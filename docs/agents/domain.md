# Domain Docs

本文件规定工程 Skills 探索代码时如何使用仓库的领域文档。

## 探索前读取

- 根目录存在 `CONTEXT.md` 时读取它。
- 根目录存在 `CONTEXT-MAP.md` 时读取其中与任务相关的上下文文档。
- 读取 `docs/adr/` 中与本次改动相关的 ADR。
- 文件不存在时静默继续，不建议或预先创建；只有在真实术语或决策需要沉淀时才使用领域建模流程创建。

## File structure

本仓库使用单一上下文布局：根目录可放置 `CONTEXT.md`，系统级架构决策位于 `docs/adr/`。

## 领域词汇

工单标题、规格、测试名和设计提案应使用 `CONTEXT.md` 定义的术语。若缺少所需概念，应先判断是否正在引入不符合项目现状的新语言；确有稳定领域缺口时再进入领域建模。

## ADR 冲突

任何输出若与现有 ADR 冲突，必须明确指出冲突及重新讨论的理由，不得静默覆盖。
