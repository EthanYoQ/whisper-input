# Whisper Input v1.5.4

## 下载

- macOS Apple 芯片：`Whisper_Input_1.5.4_arm64.dmg`
- Windows x64 安装程序：`Whisper_Input_1.5.4_x64_setup.exe`
- Windows x64 MSI：`Whisper_Input_1.5.4_x64_en-US.msi`
- Windows x64 便携版：`Whisper_Input_1.5.4_x64_portable.zip`

每个安装文件均附有 SHA-256 校验文件。

## 更新

- 修复 Qwen 实时识别的音频入队顺序、结束等待与取消恢复，减少尾包丢失和断连后的误报。
- 划词润色按请求隔离草稿，限制编辑选区长度；替换失败时仍可复制当前草稿。
- 诊断记录与导出清除识别原文、润色正文和旧错误响应正文，保留安全的错误类别与计时数据。
- 历史记录重插入前复核原编辑目标；不可确认时只复制文本。改进 Windows 多行输入、语音胶囊置顶和结构化润色。

## 安装说明

- macOS 需要 12.0 或更高版本。该 DMG 未进行 Apple 代码签名或公证，首次打开时系统可能要求在“隐私与安全性”中手动允许。
- Windows 安装程序仅适用于 x64，系统范围安装可能要求管理员权限；便携版仍依赖 Microsoft Edge WebView2 运行时。
- Windows 安装程序未配置 Authenticode 代码签名，系统可能显示来源提示。

此 Release 提供手动下载文件，不代表应用内自动更新已完成验证。
