# Whisper Input v1.5.3

## 下载

- **macOS（Apple 芯片，M1 及更新机型）**：`Whisper_Input_1.5.3_arm64.dmg`
- **Windows x64 安装程序**：`Whisper_Input_1.5.3_x64_setup.exe`
- **Windows x64 MSI 安装包**：`Whisper_Input_1.5.3_x64_en-US.msi`
- **Windows x64 便携版**：`Whisper_Input_1.5.3_x64_portable.zip`

本 Release 的每个安装文件均附有 SHA-256 校验文件。

## 桌面界面更新

- 更新为半透明毛玻璃桌面界面，并保留系统原生材质不可用时的稳定回退。
- 新增浅色 / 深色模式切换；主题偏好会同步到应用的多个窗口。
- 优化桌面窗口生命周期与语音胶囊呈现，避免主窗口焦点变化干扰输入流程。

## 其他改进

- 轻量润色在 Gemini 的首个流式片段到达时即可上屏，并记录 ASR、模型和写入各阶段耗时。
- 高级 ASR 可选择 SiliconFlow 自动预填，或连接任意 OpenAI Audio Transcriptions 兼容的云端或本地服务。
- Windows 文本写入优先使用 Unicode 键盘事件，失败时保留剪贴板回退；本地启动不再依赖可见终端窗口。

## 安装说明

- macOS 需要 12.0 或更高版本。该 DMG 未进行 Apple 代码签名或公证，首次打开时系统可能要求在“隐私与安全性”中手动允许。
- Windows 安装程序仅适用于 x64。标准安装使用系统范围安装模式，可能要求管理员权限；便携版无需安装，但仍依赖系统的 Microsoft Edge WebView2 运行时。
- 当前发布流程未配置 Windows Authenticode 代码签名，Windows 可能显示来源提示。

此 Release 统一展示 GitHub 下载文件；不代表已新增或验证应用内自动更新。
